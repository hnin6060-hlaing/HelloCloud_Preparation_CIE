Access key, secret access key has lifetime accessment. So, vault can rotate key.

-dev-listen-address=0.0.0.0:8200

  • Public / Network-wide. Accessible from any device on local network, remote clients, and outside Docker containers.
  • Binds to all available network interfaces on the host machine.
  • Running Vault inside a Docker container, VM, or an AWS EC2 instance where external tools need to connect.

-dev-listen-address=0.0.0.0:8200

  • Localhost-only. Only accessible from the exact machine or container where Vault is running.
  • Binds strictly to the loopback interface.
  • Basic local development directly on workstation operating system.

➜  vault server -dev -dev-listen-address=0.0.0.0:8200
